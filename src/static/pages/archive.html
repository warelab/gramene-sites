Archive

archive.gramene.org is an instance of Gramene's build 39 which was the last to support the following legacy datasets:

* QTL data

* Comparative maps

* Gramene Curated Genes & Alleles Database (e.g., rice mutants)

* Gramene Markers Database

* Gramene Proteins Database

* Gramene Ontologies Database

* Gramene Literature Database

* Cyc Pathways
